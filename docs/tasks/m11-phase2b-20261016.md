## 关键设计决策

|决策|依据 / 必须保持|
|---|---|
|多静态bitstream|MMCM/BUFG/ODDR，Q由CLKOUT2/2B、QM由3/3B，各独立；不在运行中切Fabric时钟MUX|
|16点 / 最少3点可靠窗口|75/100/125MHz步进833.333/625/500ps；1或2点保守MARGINAL，全部候选窗保留|
|参考事务边界|D于nT+T/4发b[n]；Q=b[n−1]，QM0..7=b[n−1]、8..15=b[n]；Q15→0不合窗，QM7→8不合、15→0可合|
|PRBS31|x^31+x^28+1，左移反馈bit30 XOR27，输出旧30，seed13579bdf；冻结/停止不得误推进|
|统计 / CDC|两路64bit本域计数；完成冻结256bit快照，done同步+额外稳定等待；禁止逐位同步递增计数器|
|时序例外|只对未知外部pad→IOB及首级控制同步、复位同步PRE端局部例外；所有内部数据路径保留STA|
|频率分类|可靠多点窗口+模式/百万/亿次门控才频率PASS；125MHz亿次单点零错仍MARGINAL|
|构建预算|--jobs2，仅预构建当前频率未完成点；扫描结束后本频率长测，再下一频率；避免OOM及预算额外+1|
|协议兼容|Phase1v1和旧v2仍解析；独立首错字段可选，不能破坏旧数据|

系统50MHz、UART115200、IO LVCMOS33 DRIVE12 SLOW；名义3.3V、实际V/T未知。相位ps为配置推导值，未标定绝对延迟。
