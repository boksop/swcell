## 关键设计决策

1. 高 4 位 major opcode，子编码、保留位和 flags 明确在软件 ISA 文档；15,015 合法、50,521 保留编码，保留位非零 TRAP，无副作用。
2. LD/LDI/logic 更新 Z 保留 C；AR_CTRL/IO 保持 Z/C；减法 C=无借位。MOVA/IN 改 A 但不改 Z，要判断需显式操作。后续 RTL 必须按版本匹配。
3. 普通 2、RAM 5、reset 单列 1 为候选软件成本；不是 RTL 微周期/传播延迟仿真，不证明 328 MUX、主频或完整帧率。
4. RETURN_ID 占普通 RAM F0，单层调用，函数以现有指令分派，无 CALL/RET/LR/栈；参数和分派全部纳入动态计数。
5. Snake 食物为 CPU 有界线性探测，非随机；损坏位图 65 次候选后显式诊断。身体环/位图/增长/碰撞由机器程序完成。
6. 逐场景夹具只在 CPU 启动前装载；独立数学模型只核对输出。另测脏 RAM boot 与连续循环，防止宿主更新掩盖指令程序问题。
7. 游戏镜像分别链接；暂未合并镜像。未实现 OLED/SPI/软件消抖/WAIT，不把旧 747 预算套用到新架构。
8. 子 Agent 分别完成通用工具/Pong/Snake，根维护 oracle、预算、回归、文档和进度；最终只读交叉复核已通过。修复预算辅助 drive 恰好在 limit 抵达断点的边界并覆盖测试。
