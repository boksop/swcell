# M11 低速功能测试计划

## 电路含义

74LVC1G157 为 `Y=S?B2:B1`。U236：B1=Q反馈、B2=D、S=EN。U237：B1=D、B2=QM反馈、S=CLK。U238：B1=Q反馈、B2=QM、S=CLK。因此低 CLK 时 Master 透明、Slave 保持；高 CLK 时 Master 保持、Slave 透明。组合应呈现上升沿 DFF 的低速稳定功能，但不假定等效于标准时序单元的动态特性。

七个 IO 的方向严格按板外电路：输出 DL_D、DL_EN、DFF_D、DFF_CLK；输入 DL_Q、DFF_Q、DFF_QM。默认 500 ns 步骤、至少 200 ns 传播预算，并额外校验同步器/比较余量。

设 `N=PATTERN_STEPS`（默认 32，至少 8），`R=RANDOM_STEPS`（默认 1024）。表中检查数不含初始化和准备阶段。所有初始化/准备刺激也经过完整步骤等待。

## D-Latch

每项首先 `EN=1,D=0`，确认电路有机会进入确定状态；初始化不记录检查。L03–L05 另先透明置 1，再以 `EN=0,D=1` 关门。

| ID | 刺激 | 稳定后预期 | 检查数 |
|---|---|---|---:|
| L01 | 初始化后 EN=1,D=0 | Q=0 | 1 |
| L02 | EN=1,D=1 | Q=1 | 1 |
| L03 | 透明置1并关门，D 从1变0 | Q保持1 | 1 |
| L04 | 透明置1并关门，先D=0再D=1 | 最后Q保持1 | 1 |
| L05 | 透明置1并关门，再EN=1,D=0 | Q更新为0 | 1 |
| L06 | 置0后独立关门，D=0101…翻转 | 每步Q均保持0 | N |
| L07 | EN恒1，D=0101…连续翻转 | 每步Q跟随D | N |
| L08 | PRBS31 改变D与EN | EN=1更新，EN=0保持 | R |

L04 的中间 D=0 是准备步骤；L03 负责该保持状态的独立判定。L06 在关门后才改变 D，避免将关门边沿和数据变化混为保持测试。

## DFF

每项先 `CLK=0,D=0`，再独立步骤 `CLK=1,D=0` 建立 QM=Q=0，均不计数。F01–F06 对每个数据位执行三个检查阶段：

1. CLK=1 设置 D，等待：QM、Q 均保持上一个已采样数据。
2. CLK=0，等待：QM 更新为当前 D，Q 保持。
3. CLK=1，等待：QM 保持，Q 取得该 QM；之后才推进数据发生器。

即使常量数据不变也执行这三个阶段。上升沿预期取低相位已稳定的 Master，避免一周期偏移。

| ID | 数据/刺激 | 检查要求 | 检查数 |
|---|---|---|---:|
| F01 | 全0 | 三阶段 Q/QM | 3N |
| F02 | 全1 | 首次捕获1，之后三阶段 | 3N |
| F03 | 010101… | 每数据位三阶段 | 3N |
| F04 | 00110011… | 每数据位三阶段 | 3N |
| F05 | 00001111… | 每数据位三阶段 | 3N |
| F06 | PRBS31 | 每随机数据位三阶段 | 3R |
| F07 | CLK=0，D=1010…变化 | QM跟随D、Q保持0 | N |
| F08 | CLK=1，D=1010…变化 | QM、Q均保持0 | N |
| F09 | CLK=0 多次改变D，最后强制D=1，再单独上升沿 | 低相位QM跟随、Q保持0；最后Q=QM=1 | N+1 |

PRBS31：`x^31+x^28+1`，种子 `31'h13579bdf`，移位 `state<={state[29:0],state[30]^state[27]}`，输出旧 `state[30]`；L08 的 EN 取同一旧状态的 `[15]`。种子为0时公共发生器替换为1避免锁死。每项 start 重启序列，首位在 advance 之前使用；这是可重复的伪随机功能覆盖，不是模拟噪声源或长时间 BER 资格测试。

## 数量、故障覆盖和验收

17 个子测试总检查数为 `6 + 20N + 4R`。板级默认 N=32、R=1024 共 4742 次；回归 N=8、R=64 共 422 次。总检查数按检查事件计，不把 Q 和 QM 算成两次。

回归场景：

| 场景 | 故障 | 精确预期 |
|---|---|---|
| fault=0 | 无 | 17项PASS、422检查、35条UART JSONL |
| fault=1 | L07期间反相外部 DL_Q | L07的8检查全错，Q错误8，QM错误0 |
| fault=2 | F08期间仅反相外部 QM | F08的8检查全错，Q错误0，QM错误8 |
| fault=3 | F03期间同时反相外部 Q与QM | F03的24检查全错，Q错误24，QM错误24，error_checks为24 |

每个故障场景只有一个子测试 FAIL，整套 COMPLETE FAIL，输出一条 FIRST_ERROR，共36条 JSONL。错误只改变观测路径，不改 DUT 驱动、参考模型或行为模型状态。

TB 检查独立模型下参考值的一致性、各测试刺激/相位、PRBS 的固定64位黄金向量、精确计数、首次快照不覆盖、消息数量、UART 起止位/字节序、自动结束及超时。Python 再验证每条消息的 JSON、顺序、计数、状态与快照掩码。额外运行20MHz/700ns/三级输入同步和实际板卡50MHz配置。全部M11场景使用无外部复位的板级封装，仿真缩短POR为16周期；独立POR测试验证首个时钟前复位、保持周期数和同步释放。UART 单元测试以100MHz/115200验证四种字节和帧内复位恢复。

以上为带7ns传播延迟的理想功能仿真，不证明实物的毛刺宽度、竞态窗口、IO 电气兼容性或亚稳态 MTBF。板卡实测必须使用真实约束和实际连接。
