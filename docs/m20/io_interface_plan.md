# M20 OLED、六键与辅助接口规划

## 1. 逻辑接口提案，全部物理连接TBD

|CPU视角信号|方向/位数|职责|
|---|---|---|
|SPI_SCLK|输出1|软件产生边沿|
|SPI_MOSI|输出1|CPU产生每个数据位|
|DISP_DC|输出1|命令/数据选择|
|DISP_CSn|输出1|片选|
|DISP_RSTn|输出1|独立显示复位，仍需确认屏幕是否需要该线|
|KEY_RAW|输入6|原始按键电平，极性/上拉/接地方式TBD|
|KEY_SYNC|内部6|两级同步后供IN读取|

以上名称是规划符号，不声明现有PCB网络或PACKAGE_PIN。供电、电平、屏模块上拉/电平转换是否存在均需确认。不能因M11为3.3V就默认屏模块所有接口也是3.3V兼容。

建议GPIO映射`GPO[3:0]={CSn,DC,MOSI,SCLK}`。OUT0写这4位，OUT1写RSTn=A[0]。IN0读四键，IN1读另外两键且高位补0；K0..K5具体对应方向/开始/操作由用户冻结。初始化GPO=8、RSTn=0，由CPU软件完成延时、释放与屏初始化。

复位期间不能依赖尚未初始化的GPIO寄存器：输出安全门使RSTn=0、CSn=1、SCLK=0，MOSI/DC此时无意义。三路安全覆盖连同端口合法性列入IO控制预算；有效复位含原始复位的立即安全作用和同步释放。真实板的复位脉宽必须包含足够有效时钟（初拟至少3个完整周期，器件/释放裕量待定），不能假定2-MUX DFF具有标准异步清零脚。

## 2. 软件SPI先行

基线不设SPI移位器：CPU决定字节、拆位、CS/DC状态及每次SCLK高低变化。SPI模式、位序、最小脉宽、片选/DC建立保持必须以实际屏控制器规定冻结；性能文档只是以MSB-first、类mode0事务为条件例子，不是已确认屏规格。

四位数据不能一次装入8位SPI字节；叶例程从约定RAM参数槽取高/低nibble，逐4位发射。A/B参与拆位，GPO也由程序写。单层CALL仅用于叶字节发送；主循环展开“选页/列、像素字节、循环控制”，不在CALL例程里再CALL。不得在FPGA后台把CPU的一个“画球”输出扩展为整帧。

未来若bit-bang成为实测瓶颈，可评估最小SPI发送外设：8位带使能移位状态约24颗，3位计数约9颗，busy/分频/控制等约17–57颗，**约50–90颗157额外规划量**。这是通信串行化，不允许承担碰撞/游戏状态；仍须P1按实际结构计数。首版不默认加入，不用FPGA硬SPI掩盖预算。

## 3. 刷新与RAM

推荐CPU维护少量脏单元而非完整帧缓冲。条件性例子：若最终是128×64、页高8像素且支持直接页/列写，可把逻辑棋盘映射16×8个8×8像素单元，一个实心单元输出8个像素字节。每次先算应该显示的像素，再输出命令/数据。

该例不锁定型号/分辨率。屏若要求其它寻址、I2C、9位串行或全屏更新，必须重算ISA软件量/刷新预算。不能仅改外设模型而保留不适用的帧估算。

128×64单色帧本身需1024字节=2048nibble，超过本提案256nibble RAM。因而“全屏缓冲”不是目前免费功能；若引入更大RAM地址空间或外部帧存，CPU接口/寄存器及预算必须重开评审。FPGA的OLED观察模型可内部保存1024字节，仅用于解码CPU已发送的显示字节，不能让CPU访问额外隐藏RAM。

脏区域擦除必须由CPU重新判断该单元是否仍有球拍/球/蛇/食物，不能简单擦旧图时破坏重叠新图。显示观察模型只能检查/显示已经收到的事务，不能“修正”CPU画错的图。

## 4. 六键处理

六键各两级DFF同步，12状态位，24颗157折算；可能需要的六路极性归一化也计入。异步按键接点不直接进入CPU译码或控制状态。软件进行轮询、稳定判定、方向优先级与消抖；无中断控制器、无FPGA独立去抖状态机替代真实CPU软件。

消抖目标可先评审10–20ms，但实际时间必须由冻结CPU周期及程序循环计数算出，不能根据FPGA系统50MHz直接硬套。同步器不能消除机械抖动，也不能在无实测参数时证明MUX DFF亚稳态MTBF。

## 5. 职责与禁止越界

|功能|CPU机器程序|真实简单外设/PCB|FPGA测试辅助|
|---|---|---|---|
|球/蛇位置、碰撞、分数、食物|全部执行|无|只观察，不计算后回写|
|数组、位图、栈替代|CPU地址/读写|SRAM存数据|只模拟相同容量和时序的SRAM|
|取指、译码、分支、寄存器|CPU核心|ROM存机器码|不得由MicroBlaze/软核代执行|
|SPI字节、边沿、初始化|软件bit-bang|屏控制器接收，电平/复位器件TBD|可译码/验证CPU字节，不生成游戏像素|
|按钮|CPU同步+轮询/软件消抖|按键/上拉/必要电气保护|可注入六路开关波形|
|调试|非游戏输入输出语义|可留探测点|UART、轨迹BRAM、单步/暂停、检查器；单列为非157 CPU资源|

FPGA终端或PC GUI若将字节解码成画面只是观察；PC不能算下一帧并写CPU内存。主机只允许在复位/装载阶段提供程序和初始测试镜像；运行中写RAM必须属于明确标记的故障注入，不能作为正常游戏结果。
