# V2.4-C/D：单参考同步存储服务设计

2026-11-04，已实现的数字接口契约，执行结果见[完整系统验证](M20_V24_FULL_SYSTEM_VERIFICATION.md)。用户已授权在明确数字假设下继续C/D；缺乏实体min不再阻塞数字功能验证，原B失败和物理风险不变。

服务50MHz（20ns），B参考由FPGA寄存分频为1MHz，C参考由独立仿真源约1MHz并送相同发生器/服务输入。两模式使用同一个20-MUX固定TAP16连接及既有独立传播模型。选定链每级2ns、ROOT29ns、33叶端不利损失7ns、有效D1/D2目标22ns。CPU仍477组合＋66反馈存储，不改变ISA/2-5微周期契约。

## 服务事件（不使用Johnson/V23内部相位计数）

CLK_REF经两级ASYNC_REG和历史值检测，数字识别延迟约40～60ns；实际亚稳态、MTBF及板级IO另列。记录同步电平持续age，所有事件由该外部可达参考及50MHz计数导出，不把H/S死区当BRAM访问窗口。

|事件|相对于同步边沿|相对真实边沿的数字预算|作用|
|---|---|---|---|
|RAM_SAMPLE|低age4|下降后约140～160ns|锁存CE/OE/WE、地址、数据，启动2服务周期同步读|
|PREVIEW|低age14|下降后约340～360ns|在Master稳定透明期快照旧状态/退役及总线；仅驱动参考FF更新，不驱动实体CPU|
|WRITE_COMMIT|高age0|上升后约60～80ns|将此前pending写持久化一次；CPU已由实际两相更新|
|OBSERVE|高age4|上升后约140～160ns|比较更新后的CPU架构状态、确认本微周期一次完成|
|ROM_READ|高age8|上升后约220～240ns|采样更新后的PC，2服务周期后更新并保持ROM输出|
|RELEASE/PARK窗口|高age12|上升后约300～320ns|事务排空、ROM返回后安全钳位；或在稳定高窗口解除钳位等待下一完整Master低窗口|

age0的具体采样边沿及NBA顺序以波形/断言核实，不能将表中范围当实体保证。REF半周期须容纳最坏同步识别＋age14事件＋CPU建立裕量；本轮B/C最小半周期约500ns，不支持任意升频。BRAM返回不依赖几十ns死区。

## ROM/RAM与提交定义

复用冻结V23的纯FPGA同步 `swc_fpga_memory_adapter` 数据存储部件，新增服务事件与控制层。ROM4096×16、RAM256×4，地址保持、返回输出寄存；没有让FPGA解释CPU指令或替CPU计算。RAM读取在低窗口返回，ROM只在高窗口更新；其余时间保持。

写持久点定义为本次上升交接后的WRITE_COMMIT，与V23 Master-close内部CE不同，明确作为新服务契约。RAM_SAMPLE记录pending，WRITE_COMMIT后清除，因此停在持续WE有效状态也不会重复写。RESET在持久点之前取消pending，已持久写不回滚；CPU复位不清RAM。OBSERVE在持久点之后，允许比较架构/RAM一致性。

PREVIEW是验证/总线快照点，不是CPU物理提交点。V1/V21理想FF参考可在此采样旧D，随后在OBSERVE与真实锁存CPU比较；CPU的477组合和33状态仍只由真实H/S控制。独立模式A继续使用原V23调度器/适配器，其结果按事件序号比较，墙钟频率与B/C分开报告。

## 控制契约

SAFE_HOLD高为H=1/S=0；参考持续运行。正常STOP在高age12、写/ROM完成后钳位，再等待4服务周期确认parked。STEP只在step_ready时接受一个上升沿，忙时不排队；接受后暂存待启动，在合格高窗口释放，忽略旧QM重开，直到下一低窗口才激活服务，完成恰一PREVIEW/OBSERVE后重新停车。STOP优先于同拍STEP，CPU_RESET期间STEP忽略；RUN可用于复位初始化完整相位序列。

初始化须实际运行两个Reset有效的Master/Slave周期并核对33位，不以钳位或变量初值代替。HALT/TRAP可继续输入空微周期但不得有退役或RAM事务；终态STEP只保持状态。调度器RESET为紧急初始化，正常STOP不直接异步切断参考。
