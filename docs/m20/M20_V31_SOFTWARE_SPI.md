# V3.1 软件SSD1306与接口契约

SPI仅由CPU OUT写GPO产生。CS/DC/SCK/MOSI直接连接GPO[3:0]；每bit执行数据/低时钟OUT、高时钟OUT、低时钟OUT；每字节8个MSB-first上升沿，末尾CS回高。每个SPI边沿都可回溯至实际OUT退役，记录见joint_r5/cpu_out.csv及同目录Python spi_bytes.csv。FPGA无移位器、像素生成或命令解析，解析器只在外部Testbench中。

初始化沿用实机已验证配置：AE,D5/80,A8/3F,D3/00,40,8D/14,20/02,A0,C0,DA/12,81/7F,D9/F1,DB/40,A4,A6,2E；Page模式，A0/C0适配180°安装，先清1024字节再AF。菜单/重开可软件清屏但不拉OLED硬件复位。

软件地址例程发送B0|page、列低nibble、列高nibble。绘图使用字节完整替换，避免假定SPI可读回显存；8×8单格独占8列，CPU重生成格内容。球/食物的加号逐列为00/00/18/7E/7E/18/00/00，不能将同一字节重复8次冒充加号。比分3×4字形用普通立即数字令，不用FPGA字体表。紧凑比分覆盖Pong顶行部分列，这是当前简化布局的显示取舍，游戏坐标/碰撞/计分仍沿用原规则。

|参数|当前测得/推导|来源|
|---|---|---|
|系统时钟|50MHz|已确认板卡及XDC设定，本轮未用仪器测量|
|CPU微周期|1MHz|50系统拍/CE|
|SPI上升沿间隔（同字节）|54..89μs|Python实际指令轨迹；跨nibble含控制开销|
|SPI高电平|4μs|两次OUT之间指令周期|
|MOSI最小建立时间|4μs|模型观测|
|活动SPI速率|约11.2..18.5kbit/s，非固定频率|1/上升沿间隔；字节间另有调用开销|
|UART|115200、8N1|独立FPGA诊断，非OLED时钟|

这与V3的10MHz硬件SPI不同。不能用CPU1MHz代替SPI速率，或用OLED内部扫描频率代替内容更新率。当前软件局部绘图满足约9.6/4.8Hz游戏更新；整屏清除仍约0.75秒，开机两次清屏加菜单约1.506秒软件执行时间，另加FPGA上电复位/等待。

时序参考为[Solomon Systech SSD1306 Rev1.1](https://docs.sparkfun.com/SparkFun_Qwiic_OLED_1.3in/assets/board_files/SSD1306.pdf) 的4-wire接口：最小100ns时钟周期，CS建立20ns等；本轮没有改变器件/电压，沿用当前模块初始化，独立模型检查CS/DC/8bit/高低宽度/数据建立和显示前清屏。数字时间有较大裕量，不等于板外实测。

运行中CPU复位可能中断一个SPI字节；CS回高时SSD1306丢弃未完成字节。新模型只有在明确cpu_reset时才允许这种abort，正常传输仍严格要求8bit。随后软件重新初始化、清屏。未来需增加复位恰逢SPI命令参数的专项/实机观察；本轮不把配置前IO电平、实体157时序或供电瞬态标为已验证。
