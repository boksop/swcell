# M20 V2.4：独立传播弧与有效锁存边界模型

2026-11-04。模型已实现并完成原语/反例及四抽头小型运行；本文件说明其实际语义及局限。具体结果见[M20_V24_NONOVERLAP_VERIFICATION.md](M20_V24_NONOVERLAP_VERIFICATION.md)。模型是数字实验，不是晶体管、SPICE或实体时序签核。

## 1. 两个层次严格分离

|模型|作用|不能证明|
|---|---|---|
|固定20颗结构连接|MUX真值表、16级方向、静态tap接线、实例计数、无反馈|实际死区、锁存透明边界、setup/hold|
|独立传播延迟模型|事件顺序、独立弧、负测、所有叶端有效窗口、数据穿透|实体污染延迟、亚稳态、真实脉冲电压/斜率、绝对Fmax|

零延迟结构会把延迟链化为逻辑同值关系Cd=C；因此其通过不得被汇总为非重叠时序PASS。也不能把同一参数绑定Master/Slave两颗独立器件，再只整体放大缩小而称为最坏快慢验证。

## 2. 参数范围与来源

只引用既定器件的[onsemi NC7SZ157 Rev7原厂资料](https://www.onsemi.com/download/data-sheet/pdf/nc7sz157-d.pdf)：

|资料项目|条件/内容|分类|
|---|---|---|
|数据/选择传播|3.3V相关AC表为typ/max，未列保证min|datasheet|
|50pF/500Ω测试点|In→Z典型3.2ns、全温最大5.0ns；S→Z典型3.2ns、全温最大5.2ns|datasheet，限所列测试条件|

|Master/Slave有效开启/关闭、setup/hold|普通MUX资料不提供此自构锁存器完整规格|assumed或NOT_VERIFIED|

数据手册值不自动适用于链中较小负载、极慢RC输入或全部工艺组合。任意assumed最小值扫描通过，仍只能得到CONDITIONAL结论。

## 3. 独立参数的最小集合

- DELAY01～16分别配置数据上升/下降；允许负载/走线附加模型，不把未选后级裁掉。
- OR与AND分别配置I0/I1数据弧及SELECT弧，上升/下降独立。
- 两颗SAFE_HOLD分别配置数据通过弧与钳位选择弧；允许保持信号分配不匹配。
- Master与Slave Buffer分开；每相六分支，每分支5或6个叶端，总计33。两相不能共享一个“统一时钟延迟”。
- 全部33个Master、33个Slave独立定义有效打开/关闭边界及数据传播；不要求相同型号的独立器件具有相同延迟。

例如每相分支可按6/6/6/5/5/5分组，但分组只是时序模型映射，不是Buffer型号或PCB放行。每个候选型号的真实延迟/输出skew/输入负载均需后续证据，不能将一组通用假设标成五款Buffer保证值。

## 4. 实际事件与窄脉冲语义

`sim/m20_ff16/swc_ff16_timing.sv`实现逐输入端的惯性连续赋值：`assign #(dr,df)`分别延迟I0和I1，`assign #(sr,sf)`延迟SELECT，再以延迟后控制选择延迟后数据。时间分辨率为1ps。每颗芯片有独立dr/df/sr/sf；当前同一芯片的I0与I1分别维护延迟事件，但复用该芯片同一组dr/df数值，不能称两数据输入已各自校准。

短脉冲可能取消同一延迟输入端尚未完成的转换，属于该惯性模型的语义，不是实体模拟滤波保证。多个输入接近变化时按各自到达时刻及delta-cycle逻辑求值。本轮原语自测实际核对DATA上/下降、SELECT上/下降、一个短脉冲的惯性取消，并用真实反馈MUX在上升/下降两个方向观察穿透。不能把该自测扩展为任意脉宽或真实芯片滤波结论。

锁存器Master使用独立`m_close/m_open`控制有效选择边界，Slave使用独立`s_open/s_close`，两颗芯片不再绑定同一SELECT数值。数据上/下降另有参数。有效开关边界已经表示选通过程，不再重复叠加同一SELECT传播弧。33对各有独立路径和有效参数。

### 完整脉冲的重汇合不能省略

设链相对输入边沿的上/下降延迟为τr/τf，译码H/S的数据弧为drH/dfH、drS/dfS，选择弧为srH/sfH、srS/sfS。当SAFE_HOLD持续释放、输入完整稳定，钳位前译码事件相对参考边沿为：

```
Hr = min(srH, τr + drH)
Sr = max(srS, τr + drS)
Sf = min(sfS, τf + dfS)
Hf = max(sfH, τf + dfH)
```

OR上升可由选择或Cd数据中先到的一条触发；AND上升需要两条条件均到达。下降反之。之后再加入独立钳位通过路径、Buffer和叶端有效参数。窄脉冲/保持竞争时该完整脉冲公式不代替逐事件仿真。

快速链TAP4的τ=2ns，H选择上升4ns但Cd数据路径3ns已使H上升，因此关闭重汇合走3ns，不能机械使用4ns。该场景实际D1/D2为−7ns，不是简化公式给出的−8ns；负值仍是失败，修正公式不是放宽断言。

## 5. 全局D1/D2

对某个交接周期k，记录每个叶端的实际有效边界时间：

```
D1[k] = min_j(SlaveOpen[k,j]) − max_i(MasterClose[k,i])
D2[k] = min_i(MasterOpen[k,i]) − max_j(SlaveClose[k,j])
D1_min = min_k D1[k]
D2_min = min_k D2[k]
```

i、j均覆盖0…32，允许最坏Master和Slave在不同位、不同分支。只计算33对同位差值是不充分的。D1/D2为负表示模型有效透明区重叠；为零不代表已有setup/hold裕量。要求的正guard也必须注明assumed或测量来源。

参考边沿、tap/Cd、钳位输出、Buffer输出和有效边界应分别保存。发生器H/S节点不重叠，只是必要观察之一，不能替代以上全局判定。

## 6. 必要的小型验证与结论标签

先运行四tap相同参数集，覆盖正常上/下降、M慢关/S快开及反向、局部混合快慢、译码/钳位/Buffer差异、占空比/抖动/窄脉冲、负载变化，以及故意过短延迟。失败至少保存最小反例、所有参数、时间戳、Q/QM、是否穿透和预期/实际判定。

|标签|含义|
|---|---|
|VERIFIED|已执行并通过特定数字检查，例如实例/真值表；不自动扩大到物理|
|CONDITIONAL|仅在列明assumed参数及激励范围内得到满足裕量的结果|
|NOT_VERIFIED|未执行、模型不能表达或缺失物理参数|
|FAILED|实际仿真反例/断言失败；负测的故障被正确检出可另标“检测有效”|

负测必须能产生被观测的有效重叠；数据激励应使穿透可见，不能因D恰好不变而把模型失灵与电路可靠混淆。所有tap均无可信窗口时停在本层，不启动完整CPU。

## 7. 本轮结果和覆盖边界

实际`small_r4`共56项。nominal四tap全局D1/D2为8/16/24/32ns；independent_cross两方向为−2/6/14/22ns；上/下降2/1ns非对称链的D2为−6/−2/2/6ns。fast_chain_sensitivity两方向为−7/−6/−4/−2ns，四tap均每次出现4个跨寄存器流水错误，虽然同位重叠计数全为0。最坏位分别来自不同叶端，不能裁成同位比较。

正常保持场景在park/resume期间继续检查全局me/se与Q保持。晚释放SAFE_HOLD每tap均缺失一个Master窗口且有数据错误；3ns高脉冲场景没有完整配对窗口，D1/D2在结果为null，而非0或“无重叠通过”。后者不能用来宣传输入窄脉冲被可靠滤除。

三类注入/敏感性与11个normal_assumed场景均保留：32项CONDITIONAL、24项FAILED。TAP16在11个normal场景的最坏6ns超过assumed 4ns guard，但没有排除0.5ns快速链敏感性；因此物理为NOT_VERIFIED，项目门槛为STOP_BEFORE_C_AND_D。原始配置JSON、trace、错误CSV及[结果表](ff16_resources/timing_results.csv)共同支持结论，未启动CPU完整回归。

## 8. B深化分析的附加边界

新 `ff16_review.py` 对上述模型作独立完整脉冲解析，并直接复核实际trace的有效事件时间。新增分配字段分开记录芯片公共传播、输出分支、PCB和锁存开闭；原模型聚合Buffer参数不能据此被追认为已物理辨识。全局最坏取全部33×33组合，原测试位和CPU物理位置仍未建立映射。

特别注意本模型的时序语义：已稳定DATA在有效SELECT开放时可立即被选到Q，因此设置的Slave DATA=0.1ns不是保证的CLK→Q最小值。新CPU路径分析将CQ_min取0，数据路径按冻结MUX的实际DATA/SELECT输入连接延迟；不能重复叠加一项并因此证明Hold安全。

完整脉冲公式只在高/低窗口足够隔离且无SAFE_HOLD竞争时使用。频率扫描超出域明确标记FULL_PULSE_FORMULA_NOT_APPLICABLE；必要控制窗口计算不是新事件仿真。带延迟局部实验只活动源/目的存储单元、其余状态固定，不是完整CPU执行或任意多输入冒险验证。结果与进一步约束见[深化评审](M20_V24_ARCHITECTURE_REVIEW.md)。本轮未改动原模型SV。
