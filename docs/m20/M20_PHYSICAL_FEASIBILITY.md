# M20：真实157 CPU物理可实现性评估

2026-11-02。V2.1结构与指定数字回归 **VERIFIED**；V2.2物理规格/可配置分析已交付，物理数值为 **ESTIMATED**；完整CPU PCB投板放行 **TBD**。接受500+核心规模，不再为了300重复推翻架构。

## 结论

正式版完整验证口径477组合+66存储=543，纯CPU476+66=542；原V1/603保留。ISA/33状态/2-5profile保持，本轮重新执行50521非法终态/恢复和87场景57331事件通过。详见[V2.1结果](M20_300_V2_1_TEST_REPORT.md)。

可以继续围绕此结构进行时钟、供电、接口和小样实测；**尚不能保证任一实物主频或直接放行整板**。关键风险是主从交接、短路径与分布时钟，远不止最长组合逻辑。

## 关键物理发现

- 最长拓扑ROM→state 29层，FF→FF最多16；Top50没有被证明为真实可敏化最差路径。纯门数乘2–4ns只是粗算，不是CPU Fmax。
- 最短跨寄存器2层A→GPO未在同边沿发射；实际游戏轨迹找到79对最短路径同边沿活动见证，最短4层，包括PC0→PC1、AR0→AR1、A→C。需做真实hold/skew测量。
- clock负载为66个S；LVC典型输入电容合计165pF未含布线。建议评估非重叠两相、分支缓冲，辅助器件另计。
- 同步复位MUX能在数字模型中复位，但真实反馈DFF必须靠确定相位序列初始化；不能依赖FPGA GSR。
- FPGA ROM/RAM由固定相位适配器服务，不能省掉存储服务和IO往返时间。现有2/5周期通过模型验证，板级约束仍待闭合。
